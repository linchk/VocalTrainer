## 🎤🎹 VocalTrainer — Тренер вокала с визуальной обратной связью

**VocalTrainer** — это десктопное приложение на Java для тренировки вокальной интонации в реальном времени. Программа анализирует высоту вашего голоса через микрофон и сравнивает её с целевой нотой, заданной через MIDI-клавиатуру или встроенное виртуальное пианино.

### 🔑 Ключевые возможности

- **Точное определение высоты тона** — анализ вокала с разрешением до цента (1/100 полутона)
- **Визуальная обратная связь**:
    - Голубая линия — история вашего вокала за последние 5 секунд на фортепианной ролле
    - Жёлтая пунктирная линия — целевая нота
    - Цветовой индикатор отклонения: зелёный (±15¢), оранжевый (±40¢), красный (>40¢)
- **Гибкий ввод** — поддержка физических MIDI-клавиатур и виртуального пианино с управлением с клавиатуры ПК
- **Автопрокрутка** — автоматическое центрирование вида на текущей ноте
- **Сохранение настроек** — все параметры устройств сохраняются между сессиями
