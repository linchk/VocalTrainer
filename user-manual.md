# Инструкция пользователя: Тренер вокала (VocalTrainer)

## 📌 Назначение программы
Программа предназначена для тренировки вокала с визуальной обратной связью:
- Анализ высоты вашего голоса в реальном времени через микрофон
- Сравнение вашей ноты с целевой нотой (из MIDI-клавиатуры или виртуального пианино)
- Отображение отклонения в центах (¢) для точной настройки интонации

---

## ⚙️ Запуск программы
1. Убедитесь, что на компьютере установлен **Java 8 или новее**
2. Запустите файл `run.bat` двойным кликом
    - Скрипт автоматически скомпилирует код и запустит приложение
    - Для работы требуется поддержка кодировки UTF-8 (настроено в скрипте)

---

## 🔧 Настройка устройств (панель ⚙️)

### Первоначальная настройка
При первом запуске раскройте панель настроек кнопкой **⚙** в правом верхнем углу:

| Устройство | Действие |
|------------|----------|
| **🎤 Микрофон** | Выберите микрофон из списка (рекомендуется использовать внешний микрофон для точности) |
| **🔊 Динамики** | Выберите устройство вывода звука |
| **🎹 MIDI In** | Выберите MIDI-клавиатуру или контроллер (если используется) |
| **📤 MIDI Out** | Выберите режим вывода:<br>• **Синтезатор** (встроенный) — для прослушивания через динамики компьютера<br>• **Физический порт** — для подключения к внешнему синтезатору |

### Полезные кнопки в настройках
- **🔄 Обновить** — обновить список доступных устройств после подключения нового оборудования
- **🔊 Тест** — проверить работу аудиовыхода (воспроизведёт тон 440 Гц)
- **🎹 Тест MIDI** — проверить работу MIDI-выхода (воспроизведёт ноту Ля)

---

## 🎹 Основной интерфейс

### Верхняя часть
- **🎤 Ваша нота** — текущая нота вашего голоса (голубой цвет)
- **🎹 Цель** — целевая нота из MIDI (жёлтый цвет)
- **📏 Отклонение** — разница между вашей нотой и целью в центах:
    - ✓ зелёный — отклонение < 15¢ (отлично!)
    - △ оранжевый — отклонение 15–40¢ (нужна коррекция)
    - ✗ красный — отклонение > 40¢ (значительное расхождение)

### Центральная панель (фортепианная ролла)
- Вертикальная шкала — клавиши фортепиано (от C3 до B6)
- **Голубая линия** — история вашего вокала за последние 5 секунд
- **Жёлтая пунктирная линия** — текущая целевая нота
- При включённой **автопрокрутке** вид центрируется на текущей ноте

### Нижняя панель
- **📡 MIDI Log** — журнал событий для диагностики
- Кнопки **▶️ СТАРТ** / **⏹️ СТОП** — управление записью

---

## 💻 Виртуальное пианино

### Открытие
Нажмите кнопку **♫** в правом верхнем углу основного окна.

### Управление с клавиатуры ПК
| Клавиша | Действие |
|---------|----------|
| **A–; ' ** | Белые клавиши фортепиано (от C до B) |
| **W, E, T, Y, U** | Чёрные клавиши (диезы) |
| **+ / =** или **цифровая клавиатура +** | Повысить октаву |
| **-** или **цифровая клавиатура -** | Понизить октаву |
| **Z** | Понизить октаву (альтернатива) |
| **X** | Повысить октаву (альтернатива) |
| **📌 Поверх всех** | Флажок для фиксации окна поверх других приложений |

> 💡 Подсказка: буквы на клавишах виртуального пианино показывают соответствие клавишам клавиатуры ПК.

---

## 🚀 Рабочий процесс

1. **Настройте устройства** (микрофон и MIDI-вход/выход)
2. Нажмите **▶️ СТАРТ** для начала анализа
3. **Варианты задания цели:**
    - Нажмите клавишу на внешней MIDI-клавиатуре
    - Используйте виртуальное пианино (клавиши ПК)
4. **Пойте** целевую ноту — следите за отклонением в центах
5. Нажмите **⏹️ СТОП** для остановки

---

## ⚠️ Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Микрофон не определяется | Проверьте подключение, разрешения ОС, перезапустите программу |
| Нет звука при тесте MIDI | Убедитесь, что выбран правильный выходной порт или включён синтезатор |
| Ноты не отображаются | Проверьте громкость микрофона в системных настройках (рекомендуется 70–80%) |
| Программа «зависает» при старте | Закройте другие приложения, использующие аудиоустройства |
| Искажённый звук | Уменьшите громкость микрофона в системных настройках |

---

## 💡 Советы для эффективных тренировок

- Начинайте с простых упражнений на удержание одной ноты
- Используйте наушники для избежания акустической обратной связи
- Включите **автопрокрутку** для удобного отслеживания высоких/низких нот
- Для точной настройки следите за значением в центах — цель ±15¢
- Сохраняйте настройки: программа автоматически запоминает выбранные устройства

> 📌 Все настройки сохраняются между запусками программы.
